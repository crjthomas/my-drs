# How to Cite This Project

## BibTeX

```bibtex
@software{lbw_decision_system_2024,
  title = {LBW Decision System: Real-time Cricket Umpiring Assistant},
  author = {LBW Decision System Contributors},
  year = {2024},
  url = {https://github.com/your-repo/lbw-decision-system},
  note = {A computer vision system for real-time LBW decision making using single camera},
  keywords = {computer vision, cricket, sports analytics, object detection, trajectory prediction}
}
```

## APA Style

LBW Decision System Contributors. (2024). *LBW Decision System: Real-time Cricket Umpiring Assistant* [Computer software]. https://github.com/your-repo/lbw-decision-system

## MLA Style

LBW Decision System Contributors. *LBW Decision System: Real-time Cricket Umpiring Assistant*. 2024. GitHub, https://github.com/your-repo/lbw-decision-system.

## Chicago Style

LBW Decision System Contributors. "LBW Decision System: Real-time Cricket Umpiring Assistant." Last modified 2024. https://github.com/your-repo/lbw-decision-system.
