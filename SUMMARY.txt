================================================================================
TECHNICAL SPECIFICATIONS
================================================================================

Detection: YOLOv8 (primary) + Classical CV (fallback)
Tracking: Kalman Filter (4-state: x, y, vx, vy)
Prediction: 2nd-order polynomial + physics model
Processing: Multi-threaded (capture, process, monitor)
Performance: 20-60 FPS depending on hardware
Latency: 39-54ms end-to-end
Accuracy: 75-85% (single-camera limitations)

Hardware Requirements:
- Minimum: Intel i5, 4GB RAM, 720p camera
- Recommended: Intel i7, 8GB RAM, 1080p 60FPS camera, NVIDIA GPU
- Optimal: GPU-enabled laptop, 4K camera, tripod

Supported Platforms:
- Linux (Ubuntu 18.04+, Debian, etc.)
- macOS (10.14+)
- Windows (10/11)

Dependencies:
- Python 3.8+
- OpenCV 4.8+
- PyTorch (for YOLOv8)
- NumPy, SciPy
- Ultralytics YOLOv8

================================================================================
LIMITATIONS (Single-Camera System)
================================================================================

1. 2D vs 3D: Single camera sees 2D projection only
2. Occlusion: Batsman can block ball view
3. Depth: Hard to judge exact distance along optical axis
4. Height: Difficult to judge ball height precisely
5. In-line: Marginal "in-line" decisions less accurate
6. Lighting: Sensitive to lighting conditions
7. Ball color: Works best with contrasting ball

Accuracy: 75-85% vs professional systems (95%+)

1. INSTALL (5 minutes):
   ./scripts/setup.sh
   source venv/bin/activate

2. TEST (2 minutes):
   python scripts/test_system.py

3. CALIBRATE (5 minutes at ground):
   python scripts/calibrate.py

4. RUN (at match):
   python main.py

5. CONTROLS (during match):
   Press 'r' before each delivery (reset tracker)
   Press 's' to save screenshot
   Press 'p' to pause
   Press 'q' to quit
